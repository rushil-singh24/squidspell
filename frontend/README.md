# SquidSpell Frontend

The SquidSpell frontend shell: a Vite + React 19 + TypeScript + Tailwind v4
single-page app. It captures the webcam, runs MediaPipe hand-landmark
detection **in the browser**, streams the landmarks to the Phase 4 backend
over `WS /ws/predict`, and shows the returned prediction / confidence / FPS in
a corner readout. It also provides the shared layout both game modes plug
into: a stable left webcam pane, a Train/Race nav toggle, an animated
right-hand pane, the underwater theme with a dark/light toggle, and a small
set of reusable Framer Motion primitives.

Hand-landmark extraction is entirely client-side — the backend receives
pre-extracted `[[x, y, z] ×21]` landmark frames and never does any image
processing.

## Prerequisites

- `npm install` (Node is pinned to 22.19.0 via `../.nvmrc` and `package.json`
  `engines`).
- The Phase 4 backend running on `http://localhost:8000` for live
  predictions. The shell still renders without it — the connection readout
  just shows a disconnected state and retries with backoff.
- `../ml/models/hand_landmarker.task` present locally, so
  `scripts/copy-mediapipe.mjs` can stage it into `public/models/`. It is not
  in git (regenerable) — see the repo's `DECISIONS.md`.

## Commands

| Command | What it does |
|---|---|
| `npm run dev` | Vite dev server at `http://localhost:5173`. |
| `npm run build` | `tsc -b && vite build` — type-check then production build. |
| `npm test` | `vitest run` — the unit suite (Vitest + Testing Library + jsdom). |
| `npm run lint` | `oxlint`. |

`predev` / `prebuild` / `pretest` automatically run `scripts/copy-mediapipe.mjs`
first (see below).

## Environment

Copy `.env.example` to `.env` to override the defaults:

| Var | Default | Purpose |
|---|---|---|
| `VITE_WS_URL` | `ws://localhost:8000/ws/predict` | Prediction WebSocket. |
| `VITE_API_URL` | `http://localhost:8000` | REST base URL. |

Both are resolved once in `src/lib/config.ts`; nothing else reads
`import.meta.env` directly.

## Generated assets

`public/mediapipe/` (the MediaPipe WASM runtime) and `public/models/`
(`hand_landmarker.task`) are generated by `scripts/copy-mediapipe.mjs` — a
dependency-free Node script that copies the WASM out of
`node_modules/@mediapipe/tasks-vision/wasm/` and the `.task` bundle out of
`../ml/models/`. It runs automatically via the `predev` / `prebuild` /
`pretest` npm hooks. Both directories are gitignored; the assets are served
locally rather than from a CDN.

## What's stubbed

`src/modes/TrainPanePlaceholder.tsx` and `src/modes/RacePanePlaceholder.tsx`
are exported placeholders for the right-hand pane. Phase 6 replaces the Train
placeholder and Phase 7 the Race placeholder, both by swapping the import in
`src/components/AppShell.tsx`.
